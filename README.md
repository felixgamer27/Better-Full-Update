# Better-Full-Update
A simple update script for Arch Linux
# How this works
Just run the script and select an option
# Install
To install, you just need to download the [script](https://github.com/felixgamer27/Better-Full-Update/blob/main/full-update.sh)
## Dependencies
The script needs yay, to install it, just run this command
    
    sudo pacman -S --needed git base-devel && git clone https://aur.archlinux.org/yay.git && cd yay && makepkg -si
